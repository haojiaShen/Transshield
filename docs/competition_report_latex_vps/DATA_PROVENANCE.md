## 3. 可比性限制

旧报告的 84.47 GiB 来自 SPU LinkDetails 双端计数器，本轮 68.38 GiB 来自 Linux 环回接口 TX 增量单计。环回接口的 TX 与 RX 会镜像同一批传输字节，因此本轮只计一次 TX；这两种统计方法不能直接用来计算通信量下降百分比。

旧报告与本轮的 SPU 版本、硬件、运行负载和通信计数方法均不完全相同，所以报告只替换绝对实测值并注明口径，不将差异归因于单一硬件因素。

金融边界压力的 106.16 秒/样本和 25.30 GiB 未经过当前 VPS 原始代码同口径复跑，因此在修订版中继续保留为“原报告历史记录”，不与当前 VPS 医疗结果进行直接横向比较。
