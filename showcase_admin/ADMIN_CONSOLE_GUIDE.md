# 密捷管理控制台展示说明

## 一句话定位

这是“密捷”作品的管理员训练工作台，用于统一展示训练任务、模型资产、结果文件和部署输出路径。

## 推荐展示顺序

### 1. 登录页

说明这是管理员入口，不是普通用户页面。

重点指出：

- 支持切换训练服务地址
- 默认可连本机 `http://127.0.0.1:7863`
- 后续也可以切到远端服务器

### 2. 总览

先讲：

- 当前是否有任务在跑
- 已完成任务数量
- GPU 是否被识别
- 当前正式主线模型是什么

### 3. 训练任务

这是最核心的展示页。

重点看：

- 左侧真实历史训练记录
- 新建训练任务入口
- 右侧命令链、stdout、stderr、输出目录

现场讲解时可以强调：

1. 列表里不只是演示数据，也包含真实历史训练任务。
2. 控制台创建的新任务会走后端真实调度。
3. 每条任务都能回到日志和输出资产。

### 4. 已训练模型

重点说明：

- 模型来自真实 bundle
- 每条模型有路径、参数快照、manifest 和来源 run
- 医疗主线与历史对照线并列展示

### 5. 结果证据

重点说明：

- 指标来自真实 JSON
- 页面保留结果文件路径
- 可以把报告里的指标和这里的源文件对应起来

### 6. 环境设置

最后用这一页收束。

重点回答：

- 训练到底在哪跑
- Python 和仓库路径是什么
- 默认训练集、验证集路径是什么
- 可以切本机还是远端服务器

## 现场不建议做的事

- 不建议直接跑长任务
- 不建议现场改大量训练参数
- 不建议在远端服务不可达时强切远端地址

## 需要快速说明时的口径

可以直接说：

> 这个管理控制台不是静态展示，而是把训练任务、结果文件和部署资产统一接到了同一个入口。左侧能看历史真实训练，右侧能看命令、日志和输出目录；模型页和结果页又能继续回溯到 bundle 与 JSON 文件，因此训练、部署和报告指标之间是能闭环对上的。
